# MSWI Ash
Estimation of MSWI Ash, bulk quantities for the past, and future trends, including scenarios BAU, REC, and CIR


"model" folder contains all the python files jupyter notebooks used for data extraciton and processing, modelling, and plotting. Notebooks lablled as "1.X" correspond to data extraction and manipulation files, those labelled as "2.X" correspond to model estimation for the scenarios, and "3.X" correspond to plotting.

'function.py' stores the model functions.
